# Asset provenance

Built-in image_gen was used for the project floor texture. Final selected output: maintenance-floor.png. Two generated sprite atlases were rejected because their checkerboards were baked into opaque RGB pixels, including after an alpha-removal edit. They are not referenced or shipped with the game. Actors, props, district floors and weapon silhouettes are editable original SVG assets, authored for this project (not traced screenshots or copied game assets).

## Final floor prompt

Use case: stylized-concept. Asset type: production-ready tileable game floor texture, single square image. Primary request: an original dark cyberpunk megastructure maintenance floor texture for a top-down survival game, grounded survival-game material detail reminiscent of Project Zomboid, oppressive industrial scale. Strict orthographic straight-down view, uniform ambient neutral grey-green light, no perspective. Worn small concrete panels with chipped edges, grime in narrow seams, sparse rust stains, fine scratches, occasional recessed steel inspection plates. Flat walkable ground ONLY, no standing objects, machines, walls, text, symbols, characters, UI or strong baked shadows. Seamless repeat on all four edges, subtle low-contrast detail so gameplay silhouettes stay readable. Entire square filled edge to edge with opaque flooring.
