# Интерфейс мегаструктуры

Новый слой оформления — `gui.css`, загружается последним. Он не меняет размеры
мира, координаты canvas, правила исследования, стоимость предметов и сохранения.

- Главное меню: терминал доступа слева, массивная стена справа, один основной
  акцент на входе. Управление раскрывается таблицей клавиш. Повторяющийся фоновый
  watermark убран; отметка ранней сборки остаётся в меню.
- Убежище: компактная шапка, явный выход в забег, локация в центре. Склад и
  экипировка остаются взаимодействиями в мини-локации, не отдельными вкладками.
- Окна: единый каркас, закреплённые шапки, контрастные состояния кнопок, читабельные
  карточки ресурсов и ингредиентов. Описания источников материалов раскрываются.
- Склад: поиск без учёта регистра, фильтр наличия, счётчик результатов и пустое
  состояние. Фильтры сохраняются при обновлении запасов, не меняют сами запасы.
- Исследования: поиск и фильтры «Доступно сейчас», «Изучено», «Недоступно».
  Ввод не пересоздаёт поле и не сбрасывает фокус.
- HUD: здоровье и боезапас выделены, вспомогательные сведения менее заметны.
  Подсказки вынесены из области изображения canvas в нижнюю полоску.
- Узкие окна: страница без минимальной ширины 1120px, инвентарь перестраивается
  в одну колонку, маршрут прокручивается горизонтально, окна ограничены экраном.
  Управление игрой остаётся клавиатурным — сенсорные игровые кнопки не добавлены.
- Деревья экипировки сохраняют форму узлов, масштабирование и перетаскивание.
  Клавиатурный фокус видим; декоративные CSS-переходы учитывают reduced motion.

## Проверки

`node --test --test-reporter=dot` — логика, поиск, фильтры, переходы, загрузчик,
структура HTML и основные цвета текста. Это не проверка реальной геометрии CSS.

Ручная визуальная проверка в браузере пока не выполнена. Проверить при 1440×900,
1024×768 и ширине 390px: загрузку → меню → убежище → склад → исследования →
экипировку/деревья → забег. Проверить прокрутку окон, длинные названия, клавишу
Tab, Esc, фильтры без результатов и отсутствие горизонтального скролла страницы.
