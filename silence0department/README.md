# Тихий отдел

Браузерная игра о частном детективном бюро. Работает без сервера приложений, API, внешней модели и установки зависимостей. Для запуска нужен статический HTTP-сервер (или GitHub Pages): ES-модули не следует открывать через `file://`.

## Что изменилось

- 10 категорий дел: сомнительная смерть, пропавшие люди, хищение, саботаж, шантаж, преследователь, серийный убийца, маньяк или подражатель, заказное убийство и профессиональный наёмник.
- Три связанных места и 15 точек обследования. Осмотр, фотография, образец и сопоставление дают разные результаты; найденный источник открывает следующий адрес. Цифровые следы требуют проверки носителей, материальные — контрольной пробы.
- Анонимное обвинение с проверяемым опровержением, скрытый интерес заказчика, выбор раскрытия имён и защита свидетеля. Результаты решений отражаются в исходе.
- Личные обстоятельства персонажей, доверие, разные тона беседы, предъявление документов. Встречные связи и городские карточки основаны на общем графе.
- Чат с Кирой: локальные контекстные ответы по открытым материалам, подсказки, поддержка и сообщения о новых находках. Это игровой диалоговый движок, не подключение к LLM.
- Реальная встречная охота: 50 / 40 / 30 минут на сложностях «Наблюдатель» / «Детектив» / «Инспектор». Срок продолжается при закрытой странице. Действия могут сокращать запас и повышать заметность. Истечение срока или заметность 100 — окончательная гибель детектива. Две смены маршрута дают по 2 минуты и снижают заметность на 18.
- Верная догадка не заменяет доказательства. Нужны полная независимая цепь и источник мотива; в особых делах — также сопоставление эпизодов или расчётов. Ошибка возвращает дело на проверку без раскрытия ответа. Текст объяснения сохраняется, но его смысл автоматически не оценивается.

Код + категория + сложность воспроизводят дело. Генерация использует написанные сюжетные конструкции и детерминированную случайность. Интерес конкретной истории остаётся предметом игрового тестирования.

## Архитектура

| Модуль | Ответственность |
| --- | --- |
| `script.js` | Короткая точка входа и освобождение ресурсов |
| `src/app.js` | Сборка модулей с явным контекстом приложения |
| `src/data/catalog.js` | Справочники, сложности, люди, сценарии, обучение |
| `src/core/utils.js` | Чистые преобразования, случайность, экранирование |
| `src/domain/generator.js` | Согласованные люди, события, документы и аналитика |
| `src/domain/engine.js` | Сюжетные профили, поле, решения, угроза и ответы Киры |
| `src/domain/report.js` | Чистая проверка доказательственной цепи |
| `src/core/session.js` | Начальное состояние, открытие улик и сохранение |
| `src/core/controller.js` | Маршрутизация действий, формы, клавиатура, таймер |
| `src/core/dom.js` | Привязка постоянных элементов HTML |
| `src/ui/` | Отдельные модули поля, чата, бесед, отчёта, доски, архива, компьютера, лаборатории, поручений, блокнота, настроек, обучения и оболочки |
| `style.css` | Базовое оформление и темы |
| `styles/investigation.css` | Полевой интерфейс, чат и адаптивная индикация угрозы |

Домен не зависит от DOM и хранилища. UI получает текущее дело и действия через переданный контекст. Между UI-модулями нет циклических импортов: их связывает композиционный корень. Смысловые блоки снабжены комментариями.

## Запуск и проверка

```sh
python -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.js
```

После запуска откройте `http://127.0.0.1:8765`. Установка пакетов не нужна. Тесты проверяют 2000 сочетаний кодов, категорий и сложностей, достижимость доказательств, реплики, ложные исходы, срок, риск, сохранение и отсутствие преждевременного раскрытия.

Ручная проверка в браузере: все девять разделов, полевые инструменты и переходы, чат, доверие, документы, мобильная компоновка, черновик версии, итог и восстановление. Клавиши 1–9 переключают разделы, N открывает блокнот, ? — помощь. Карточки архива доступны через Enter и пробел.

В проекте нет Python-кода. Предписанные Ruff-проверки запускались, но Ruff в окружении не установлен; новые зависимости не добавлялись.

## Сохранения

Новая версия использует `quiet-department.case.v4`. Старый слот `v3` не перезаписывается и не переинтерпретируется новым генератором. Личный блокнот и настройки сохраняют прежние ключи. Черновики отчёта и чата восстанавливаются вместе с делом. Для повторной попытки после гибели нужно принять новое дело; обновление страницы срок не сбрасывает.
