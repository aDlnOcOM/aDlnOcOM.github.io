# Pixel8sector assets

Все ресурсы подключаются локально: игра не запрашивает модели или библиотеку с внешних CDN во время запуска.

- `vendor/three.min.js` — Three.js (MIT), WebGL-рендерер игрового мира и вида от первого лица.
- `vendor/GLTFLoader.global.js` — загрузчик glTF/GLB из дистрибутива Three.js (MIT).
- `models/kenney-blaster/` — набор CC0-моделей Kenney Blaster Kit. Они используются как готовые базовые силуэты для стандартных пушек; оригинальный текст лицензии лежит рядом с моделями.

Конструктор не импортирует готовую геометрию: созданное игроком оружие собирается рантаймом из прямоугольных воксельных блоков. Это позволяет произвольно менять размеры ствола, корпуса, магазина, прицела и насадок.

Источники: https://www.kenney.nl/assets/blaster-kit и https://threejs.org/.
