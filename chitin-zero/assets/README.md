# Графические ассеты

Игровая графика: оригинальные растровые спрайты с покадровой анимацией,
приглушённой промышленной палитрой и детализацией в духе Factorio.
Киберпанк-палитра отделена от мира и используется прежде всего в интерфейсе.

Все четыре PNG созданы встроенным imagegen для этого проекта; файлы не
заимствованы из Factorio, Titanfall, War Robots или Cyberpunk 2077.
Исходные PNG сохранены без изменения альфа-канала. Размер: 1254 × 1254.
Нормализованные границы кадров заданы в `../sprites.js`.

| Файл | Содержание |
|---|---|
| mechs.png | Три шасси по четыре шага ходьбы и четыре фазы пульсации гнезда |
| bugs.png | Четыре силуэта жуков по четыре фазы движения |
| ground.png | Повторяемая текстура промышленной пустоши |
| props.png | 16 камней, обломков, механизмов и объектов окружения |

Резчик использует быстрый анимированный силуэт сколопендры с другим оттенком;
таран — силуэт панцирника с другой насыщенностью и собственной атакой.
Направление отображается поворотом кадров, а не отдельными ракурсами.
Окружение декоративное: не блокирует движение и снаряды.

`mech.svg` — ранний оригинальный векторный концепт. В текущей игре не используется.

## Промпты генерации

Полные промпты находятся в `prompts.json`. Способ: встроенный imagegen;
для мехов, жуков и объектов запрошен прозрачный фон, для грунта — непрозрачный.
Цель — самостоятельный спрайтовый стиль, не копирование конкретных игровых моделей.
