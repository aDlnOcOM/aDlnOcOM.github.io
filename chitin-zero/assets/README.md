# Графические ассеты

Игровая графика: оригинальные растровые спрайты с покадровой анимацией,
приглушённой промышленной палитрой и детализацией в духе Factorio.
Киберпанк-палитра отделена от мира и используется прежде всего в интерфейсе.

Все восемь PNG созданы встроенным imagegen для этого проекта; файлы не
заимствованы из Factorio, Titanfall, War Robots или Cyberpunk 2077.
Исходные PNG сохранены без изменения альфа-канала. Старые атласы: 1254 × 1254;
три направленных атласа мехов: 1586 × 992. Границы кадров заданы в `../sprites.js`.

| Файл | Содержание |
|---|---|
| mechs.png | Три шасси по четыре шага ходьбы и четыре фазы пульсации гнезда |
| bugs.png | Четыре силуэта жуков по четыре фазы движения |
| ground.png | Повторяемая текстура промышленной пустоши |
| props.png | 16 камней, обломков, механизмов и объектов окружения |
| parts.png | 16 внешних деталей меха: оружие, броня, ходовая, реакторы и спецсистемы |
| mech-spectre-directions.png | Торс и четыре позы ходовой Спектра в разных ракурсах |
| mech-bastion-directions.png | Торс и четыре позы ходовой Бастиона в разных ракурсах |
| mech-vector-directions.png | Торс и четыре позы ходовой Вектора в разных ракурсах |

Резчик использует быстрый анимированный силуэт сколопендры с другим оттенком;
таран — силуэт панцирника с другой насыщенностью и собственной атакой.
Направление жуков отображается поворотом кадров, а не отдельными ракурсами.
Окружение декоративное: не блокирует движение и снаряды.

В v0.3 торс и ходовая используют новые отдельные изображения слоёв с общим
тазобедренным соединением. В каждом новом атласе пять рядов: торс, нейтральные
ноги, левый шаг, проходящая фаза, правый шаг. Используются первые пять ракурсов:
юг, юго-запад, запад, северо-запад, север. Остальные три направления отражаются
из левых ракурсов: сгенерированные правые виды были менее согласованными.
Восемь столбцов исходника сохранены, неиспользуемые не удалены.

Новая схема не использует прежние мехи из `mechs.png`, но файл всё ещё нужен
для анимации гнезда в четвёртом ряду. PNG не редактируются при сборке; точные
прямоугольники и точки соединения заданы в коде. У Бастиона нижний ряд имеет
отдельную границу столбцов, чтобы не обрезать выступающую ступню.
Один рендерер работает в ангаре, мастерской и бою. Прежние спрайты установленных
деталей сохранены; они не получили отдельных ракурсов в этом обновлении.

`mech.svg` — ранний оригинальный векторный концепт. В текущей игре не используется.

## Промпты генерации

Полные промпты находятся в `prompts.json`. Способ: встроенный imagegen;
для мехов, жуков и объектов запрошен прозрачный фон, для грунта — непрозрачный.
Цель — самостоятельный спрайтовый стиль, не копирование конкретных игровых моделей.
Для нового атласа деталей полный промпт сохранён отдельно в `parts-prompt.json`.
Для трёх направленных атласов — в `directional-prompts.json`; способ генерации
тот же, встроенный imagegen, с настоящей прозрачностью. См. `../ANIMATION.md`.
